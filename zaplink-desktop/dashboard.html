🛡️ PASSO 0 — Pré-Requisitos do Windows (Leia antes de instalar em qualquer PC) ▼
1
Google Chrome Oficial — O ZapLink usa o motor do Chrome para abrir o WhatsApp Web internamente. Sem o Chrome, o QR Code nunca aparece. [Baixar Chrome] obrigatório
2
Visual C++ Redistributable X64 — Pacote de sistema da Microsoft que o Windows precisa para processar bibliotecas nativas do Node.js. Se faltar, o app abre mas o QR Code fica em loop. [Baixar C++]
3
Executar como Administrador — Sempre clique com botão direito no ícone do ZapLink → "Executar como Administrador". Isso dá permissão para criar sessões do WhatsApp na pasta do programa.
⚠️ Atenção: Se instalar em C:\Program Files\, o Windows pode bloquear gravação de sessões. Prefira instalar em C:\ZapLink\ ou na Área de Trabalho.
🔑 PASSO 1 — Ativação da Licença ▼
1
Abra o ZapLink. Na tela de login, você verá o Código da Máquina (HWID) — é o ID único deste computador.
2
Clique no botão "📋 Copiar" abaixo do código e envie para o suporte via WhatsApp.
3
Receba sua Chave de Ativação (JWT), cole no campo e clique em "Ativar Sistema".
4
O sistema valida a chave e redireciona para o Dashboard. Pronto!
💡 Dica: Sua licença está vinculada a este hardware. Se trocar de computador, solicite uma nova chave enviando o HWID do novo PC.
📲 PASSO 2 — Conectando Números de WhatsApp ▼
1
Vá em Números no menu lateral → clique em "+ Adicionar número".
2
Aguarde o QR Code aparecer (pode levar 10-30 segundos na primeira vez).
3
No celular: abra o WhatsApp → toque nos três pontos (⋮) → "Aparelhos Conectados" → "Conectar um Aparelho" → aponte para a tela.
4
O status mudará de ⬤ aguardando_qr para ⬤ conectado automaticamente.
⚠️ Se o QR Code não aparecer após 60 segundos: (1) Verifique se o Chrome está instalado. (2) Feche o app e reabra como Administrador. (3) Instale o Visual C++.
💡 Você pode conectar múltiplos números. Cada um funciona de forma independente para disparos simultâneos.
👥 PASSO 3 — Importando Listas de Contatos ▼

2
Clique em "Importar Arquivo" e selecione seu arquivo.
3
O arquivo deve ter pelo menos uma coluna com o telefone. Formato aceito: .csv .xlsx .txt

🚀 PASSO 4 — Configurando e Executando um Disparo ▼
1
Vá em Disparo → clique em "+ Novo Disparo".
2
Nome da campanha: escolha um nome para identificar este disparo nos relatórios.
3
Lista de contatos: selecione a lista importada na etapa anterior.
4
Número remetente: escolha qual número do WhatsApp fará os envios.
5
Mensagem: escreva o texto. Use {nome} para personalizar com o nome do contato. Ex: "Olá, {nome}! Temos uma oferta exclusiva para você."
6
Mídia (opcional): anexe imagens, vídeos ou áudios. Áudios .ogg são enviados como mensagem de voz gravada, não como arquivo.
⏱️ Delays de Segurança — Crucial para Anti-Ban

O Delay Mínimo e Máximo definem o intervalo aleatório entre cada envio. O sistema escolhe um tempo aleatório dentro desse intervalo para simular comportamento humano.

Tipo de ChipDelay MínimoDelay MáximoRisco
Chip novo (0-7 dias)60s120sBaixo
Chip aquecido (7-30 dias)30s60sMédio
Chip robusto (+30 dias)15s30sAlto
⏸️ Pausa Automática — Como Funciona

A Pausa Automática interrompe o disparo a cada X mensagens por Y minutos. Isso "esfria" o chip e simula pausas naturais de um humano.

Exemplo: "Pausar a cada 20 mensagens por 5 minutos" = o sistema envia 20 mensagens, para por 5 min, depois continua. Recomendado para qualquer chip.

💡 Configuração recomendada: Pausar a cada 20 envios por 5 minutos.
🔄 Rotação de Números

Com múltiplos números conectados, ative a Rotação para distribuir os envios entre eles automaticamente. Isso reduz drasticamente o risco de banimento de um único número.

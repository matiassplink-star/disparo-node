## 🚀 Próximos Passos (Importante!)

### 1️⃣ Instalar Dependências
```bash
cd saas-admin-dashboard
npm install
```

### 2️⃣ Configurar Supabase
Ver arquivo **SETUP.md** - Passo 1 e 2 (criar tabelas)

### 3️⃣ Procurar a Chave Pública do Supabase
Você tem o URL e a chave secreta, mas precisa da **chave pública (anon key)** para o frontend.

No Supabase Dashboard:
- Settings > API
- Copie `anon public` key
- Cole em `.env.local` como `NEXT_PUBLIC_SUPABASE_ANON_KEY`

### 4️⃣ Rodar o Projeto
```bash
npm run dev
```

Acesse: http://localhost:3000

### 5️⃣ Testar
- Vá para `/auth/register`
- Crie uma conta
- Verifique seu email
- Faça login
- No Supabase, mude o plano para `admin`
- Acesse `/dashboard/users`

## 📊 Banco de Dados (Supabase)

Você precisa criar 2 tabelas. Ver **SETUP.md** Passo 1.3 para SQL completo.

### Tabela `users`
- id (UUID, chave primária)
- email (string, único)
- nome (string)
- plano (free, pro, admin)
- status (ativo, bloqueado)
- email_verified (boolean)
- criado_em (timestamp)
- atualizado_em (timestamp)

### Tabela `accounts`
- id (UUID, chave primária)
- user_id (FK para users)
- limite_envios (integer)
- criado_em (timestamp)

## 🐛 Troubleshooting Rápido

### Erro: "Cannot find module '@/types'"
Solução: Reinicie o servidor (`npm run dev`)

### Erro: "Supabase URL is required"
Solução: Verifique se `.env.local` existe e tem as variáveis

### Erro ao fazer login
Solução: Verifique se o email foi verificado (click no link do email)

### Emails não chegando
Solução: Verifique a chave Resend e se o domínio está autorizado

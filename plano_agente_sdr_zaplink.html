🧠
System prompt principal

Criar o prompt base do SDR: persona, tom, objetivo, limites e fluxo de conversa. Incluir variáveis dinâmicas como nome do lead, produto e estágio do funil.

prompt engineeringpersona SDR

Regras de atendimento

Definir arquivo JSON/YAML com regras: horário de atendimento, tempo máximo de resposta, quantas tentativas sem resposta encerra conversa, frases proibidas, escalação para humano.

rules.jsonfallback humano

Máquina de estados da conversa

Mapear estágios: NOVO → QUALIFICANDO → AGENDANDO → AGENDADO → PERDIDO. Cada estágio define quais ações o agente pode tomar e qual prompt usar.

FSMfunil

Semana 2–3
▼
🗄️
Tabelas no Supabase

Criar: leads (nome, telefone, origem, estágio, score), conversations (mensagens com role/content/timestamp), appointments (agendamentos), agent_sessions (contexto ativo por número).

SupabasePostgreSQLRLS

Camada de acesso (Repository pattern)

Criar módulo db/leads.js, db/conversations.js etc. para isolar as queries e reutilizar em todo o sistema sem acoplamento direto ao Supabase.

repository patternsupabase-js
🔒
Isolamento por usuário/cliente

Usar Row Level Security do Supabase para garantir que cada cliente do SaaS veja apenas seus próprios leads e conversas — já alinhado com a arquitetura atual.

RLSmulti-tenant

Multi-LLM — Suporte a vários modelosOpenAI, Groq, Gemini, Anthropic e mais
Semana 3
▼
⚡
Camada de abstração LLM

Criar módulo llm/provider.js com interface única: chat(messages, options). Por baixo, seleciona o provider conforme configuração do cliente.

adapter patternprovider abstraction
🔧
Providers implementados

OpenAI GPT-4o, Groq (llama3/mixtral para resposta rápida e barata), Google Gemini 1.5 Flash, Anthropic Claude 3.5 Haiku. Cada cliente do SaaS configura qual usar no dashboard.

openaigroqgeminianthropic
💰
Roteamento inteligente por custo

Conversas simples vão para Groq (ultra rápido e barato). Respostas complexas ou confirmações críticas usam GPT-4o ou Claude. Configurável por regra ou automaticamente.

cost routingfallback

Semana 4
▼
📅
OAuth2 + Google Calendar API

Integrar Google Calendar API com OAuth2. Cada cliente do SaaS conecta sua própria agenda pelo dashboard. Tokens salvos no Supabase com criptografia.

Google OAuth2googleapis npm
🔍
Verificar disponibilidade em tempo real

Antes de propor horário, o agente consulta a agenda e oferece até 3 opções disponíveis dentro do horário comercial configurado. Evita conflitos automaticamente.

freebusy queryslots disponíveis
✅
Criar, atualizar e cancelar eventos

Ao lead confirmar, cria evento com: nome, telefone, produto de interesse, link do Meet gerado automaticamente. Salva appointment_id no banco para sincronização futura.

events.insertGoogle Meet link
🔔
Lembrete automático via WhatsApp

24h e 1h antes da reunião, o sistema dispara mensagem de lembrete para o lead usando o próprio core de disparo do ZapLink já existente.

cron jobreminder

5
RAG — Agenda e base de conhecimentoO agente consulta documentos e contexto
Semana 5
▼
📚
Embeddings de documentos

Indexar: FAQ do produto, scripts de vendas, políticas de preço, objeções frequentes. Cada chunk vira um vetor salvo no pgvector do Supabase.

pgvectortext-embedding-3-small
🔎
Busca semântica no contexto

A cada mensagem do lead, fazer busca vetorial nos documentos indexados e injetar os trechos relevantes no prompt do agente antes de chamar o LLM.

similarity searchcontext injection
🗓️
RAG de agenda — horários disponíveis

Antes de propor slots, o agente busca no RAG: feriados, bloqueios especiais, horários preferenciais do vendedor. Contexto rico antes de consultar a API do Google.

calendar contextschedule RAG
🔄
Upload de documentos no dashboard

No painel Next.js, adicionar tela onde o cliente faz upload de PDFs/textos. O sistema processa, gera embeddings e salva automaticamente na base vetorial.

Next.js uploadpipeline automático

Ordem de execução recomendada: Fase 1 → 2 → 3 → 4 → 5 → 6. As fases 1 e 2 são pré-requisito para todas as demais. A fase 3 (multi-LLM) pode ser feita em paralelo com a fase 2. As fases 5 e 6 dependem de tudo anterior estar funcionando.
